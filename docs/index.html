About the data

This dataset is sourced from OpenFlights and licensed under the Open Database License (ODbL), featuring scheduled commercial domestic flight routes from 2014. This explorer allows visitors to interactively examine U.S. airport degrees, geographical distances using the Haversine formula, search efficiency benchmarks, and graph path connectivity across connected components.
